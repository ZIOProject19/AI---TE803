
# Search Algorithm

## Deskripsi
Modul Search Algorithm digunakan untuk mencari jalur koneksi antar titik dalam model rangkaian listrik.

## Algoritma
Algoritma yang digunakan adalah Breadth-First Search (BFS).

## Fungsi
- Mencari jalur dari titik awal ke titik tujuan.
- Menentukan apakah jalur koneksi tersedia dalam model rangkaian.
- Mengembalikan jalur yang ditemukan atau informasi bahwa jalur tidak tersedia.

## Teknologi
- Python
- Breadth-First Search (BFS)
