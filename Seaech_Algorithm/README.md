# Circuit 803 AI

## 1. Deskripsi
Circuit 803 AI adalah aplikasi sederhana untuk mendiagnosis konektivitas rangkaian listrik. Aplikasi ini membantu pengguna mengetahui apakah terdapat jalur koneksi antara dua titik dalam model rangkaian.

## 2. Tujuan
- Menerapkan konsep Kecerdasan Buatan (AI).
- Mencari jalur koneksi antartitik pada rangkaian.
- Membantu pengguna memahami konektivitas rangkaian listrik.

## 3. Teknologi
- **Python:** bahasa pemrograman utama.
- **Tkinter:** membuat tampilan antarmuka aplikasi (GUI).
- **Breadth-First Search (BFS):** algoritma untuk mencari jalur koneksi.

## 4. Cara Kerja Sistem
1. Pengguna memilih titik awal dan titik tujuan.
2. Sistem membaca hubungan antartitik yang tersimpan dalam model rangkaian.
3. Algoritma BFS mencari jalur dari titik awal ke titik tujuan.
4. Sistem menampilkan hasil diagnosis berupa status terhubung atau tidak terhubung.
5. Sistem menampilkan jalur koneksi yang ditemukan atau saran pemeriksaan.

## 5. Peran Kecerdasan Buatan
AI diterapkan melalui algoritma pencarian BFS dan aturan keputusan sederhana. Hasil pencarian digunakan sebagai dasar untuk menentukan status konektivitas rangkaian.

Sistem ini merupakan prototipe berbasis algoritma dan aturan, bukan model *machine learning*.

## 6. Batasan Sistem
- Diagnosis hanya berdasarkan hubungan antartitik yang telah dimasukkan ke dalam program.
- Sistem belum memeriksa rangkaian listrik secara fisik.
- Sistem belum mengukur tegangan dan arus listrik.
- Hasil diagnosis menunjukkan konektivitas dalam model, bukan jaminan bahwa rangkaian fisik berfungsi dengan baik.
