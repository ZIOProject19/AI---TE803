
# Multi-Agent System (MAS)

## Deskripsi
Modul Multi-Agent System digunakan untuk mengoordinasikan beberapa agen yang bekerja sama dalam proses diagnosis konektivitas rangkaian listrik.

## Agen yang Digunakan
1. Search Agent: mencari jalur koneksi menggunakan algoritma BFS.
2. Connection Analysis Agent: menganalisis hasil pencarian jalur.
3. Diagnosis Agent: menentukan hasil diagnosis dan memberikan saran.

## Alur Kerja
1. Pengguna memasukkan titik awal dan titik tujuan.
2. Search Agent mencari jalur koneksi.
3. Connection Analysis Agent menganalisis hasil pencarian.
4. Diagnosis Agent menentukan status dan saran.
5. Hasil ditampilkan melalui main.py.

## Teknologi
- Python
- Breadth-First Search (BFS)
- Rule-Based Expert System
- Multi-Agent System
