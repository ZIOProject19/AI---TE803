
# Expert System

## Deskripsi
Modul Expert System digunakan untuk mendiagnosis kondisi konektivitas rangkaian berdasarkan hasil pencarian jalur.

## Metode
Sistem menggunakan aturan berbasis IF-THEN untuk menentukan hasil diagnosis.

## Fungsi
- Memeriksa hasil pencarian jalur.
- Menentukan status konektivitas rangkaian.
- Memberikan penjelasan dan saran berdasarkan hasil diagnosis.

## Teknologi
- Python
- Rule-Based System (IF-THEN)
