# AI---TE803
AI Course Project - Search Algorithm and Expert System.
Program ini memeriksa apakah sebuah rangkaian elektronik terhubung dari sumber tegangan ke beban, dan menunjukkan letak sambungan yang terputus jika rangkaian tidak terhubung. Rangkaian dimodelkan sebagai graph, lalu algoritma pencarian Breadth-First Search (BFS) menelusuri jalur antar titik.
